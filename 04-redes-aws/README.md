# 🌐 Redes na AWS

## Sobre este módulo

Neste módulo comecei a entender como os serviços de rede funcionam dentro da AWS e como eles são fundamentais para conectar aplicações, usuários e recursos de forma segura e escalável.

Foram apresentados conceitos importantes como VPC, Subnets, Security Groups, Route 53, CloudFront e Elastic Load Balancer. Esses serviços trabalham juntos para fornecer conectividade, segurança, distribuição de conteúdo e alta disponibilidade para aplicações hospedadas na nuvem.

Este foi um dos módulos mais importantes até agora, pois grande parte da arquitetura AWS é construída sobre conceitos de rede.

---

## O que aprendi

### Amazon VPC

* Conceito de Virtual Private Cloud
* Isolamento de recursos na AWS
* Controle de rede
* Segmentação de ambientes

### Amazon Subnet

* Divisão lógica da VPC
* Subnets públicas e privadas
* Associação com Zonas de Disponibilidade

### Security Groups

* Firewall de instância
* Controle de tráfego de entrada e saída
* Regras de acesso

### Amazon Route 53

* Serviço DNS da AWS
* Registro de domínios
* Roteamento de tráfego

### Amazon CloudFront

* CDN da AWS
* Distribuição global de conteúdo
* Redução de latência

### Elastic Load Balancer

* Distribuição de tráfego
* Alta disponibilidade
* Balanceamento de carga

---

## Principais conclusões

Compreender os conceitos de rede é essencial para projetar arquiteturas seguras e escaláveis na AWS.

Também ficou claro como serviços como Route 53, CloudFront e Elastic Load Balancer trabalham juntos para melhorar a experiência dos usuários e aumentar a disponibilidade das aplicações.

Além disso, VPC, Subnets e Security Groups são componentes fundamentais para controle de acesso e segmentação de ambientes.
