# ☁️ Armazenamento com Amazon S3 e Computação Serverless com AWS Lambda

## Sobre este módulo

Neste módulo tive contato com dois dos serviços mais populares da AWS: o Amazon S3 e o AWS Lambda.

O Amazon S3 apresentou os conceitos de armazenamento de objetos na nuvem, enquanto o AWS Lambda introduziu o modelo Serverless, permitindo executar código sem a necessidade de gerenciar servidores.

Foi interessante perceber como esses dois serviços são frequentemente utilizados juntos em arquiteturas modernas orientadas a eventos.

### AWS Lambda

* Conceito de Serverless

---

## Principais conclusões

O Amazon S3 é um dos serviços mais utilizados da AWS por sua simplicidade, durabilidade e baixo custo.

Já o AWS Lambda permite criar aplicações mais flexíveis e escaláveis sem a preocupação de provisionar ou administrar servidores.

Também ficou claro como arquiteturas orientadas a eventos podem ser construídas utilizando S3 para armazenamento e Lambda para processamento automático.

---

## Conceitos importantes

* S3 = Armazenamento de objetos
* Lambda = Computação Serverless
* Bucket = Contêiner de armazenamento do S3
* Evento = Ação que pode disparar uma função Lambda
* Serverless = Sem gerenciamento de servidores
