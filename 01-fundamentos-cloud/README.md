# ☁️ Fundamentos de Cloud Computing

## Sobre este módulo

Neste módulo tive meu primeiro contato com os conceitos fundamentais de computação em nuvem e com a infraestrutura global da AWS.

Antes de começar os estudos, muitos termos como Região, Zona de Disponibilidade, Elasticidade e Responsabilidade Compartilhada pareciam complexos. Conforme avancei nas aulas, percebi que esses conceitos são a base para entender praticamente qualquer serviço da AWS.

Aqui reuni minhas anotações e os principais aprendizados obtidos durante esta etapa do bootcamp.

## O que aprendi

* O que é Cloud Computing
* Benefícios da computação em nuvem
* Infraestrutura Global da AWS
* Regiões e Zonas de Disponibilidade
* Escalabilidade e Elasticidade
* Alta Disponibilidade
* Modelo de Responsabilidade Compartilhada
* AWS Well-Architected Framework
* AWS Cloud Adoption Framework (CAF)

## Principais conclusões

Um dos aprendizados mais importantes deste módulo foi entender que a AWS não é apenas um conjunto de serviços, mas uma plataforma construída sobre conceitos muito bem definidos de disponibilidade, segurança e escalabilidade.

Também ficou claro que segurança na nuvem é uma responsabilidade compartilhada entre a AWS e o cliente, um tema bastante cobrado em certificações e muito importante para o dia a dia profissional.
