## 📖 Sobre o Bootcamp

Este repositório reúne os estudos, anotações, desafios de código, desafios de projeto e laboratórios desenvolvidos durante o bootcamp **GFT - Fundamentos de Cloud com AWS**, oferecido pela DIO em parceria com a GFT.

O programa tem como objetivo desenvolver conhecimentos fundamentais em computação em nuvem utilizando a Amazon Web Services (AWS), abordando conceitos essenciais de infraestrutura, segurança, arquitetura, armazenamento, banco de dados, automação e boas práticas de mercado.
